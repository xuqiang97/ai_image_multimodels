## 🔑 核心概念

### 三模型 = 协作「配方」关系

不是赛马、不是备份。三模型**并行产出**，每模型承担"配方"中的一部分张数与图片类型。

### 模型清单

| 名称         | 缩写  | 配色  |
| ------------ | ----- | ----- |
| LinkFox      | LF    | 蓝    |
| 自研         | 自研  | 绿    |
| 阿里绘蛙     | 绘蛙  | 橙    |

未来可扩展（如豆包），架构 / UI / 数据结构均已预留。

### 涉及范围

- 任务管理 3 层：**L1 列表** / **L2 审核工作台** / **L3 沉浸式大屏**
- 双版本：**美工版**（系统 SKU 维度，4 类图片）/ **运营版**（店铺 ASIN 维度，5 类图片，含标普 A+）
